本站不追求教科书式面面俱到，更偏向一线工程手记：记录每一次架构决策背后的思考、踩过的坑以及当时得出的结论。笔记会随项目实践持续迭代更新，前后内容观点冲突时，以最新版本为准。

## 主要写什么

本站更偏向**一线工程开发**，而不是系统教程。内容大致分这几类：

- **实习与开发踩坑**：实习和项目里真实遇到的坑、当时怎么排查、最后怎么绕过去的，把过程和结论都记下来，避免下次再掉同一个坑
- **技术栈与工程难点**：日常开发里用到的技术栈（TypeScript / Next.js / Node 等），以及做某个功能时遇到的难点、权衡和最终选型思路
- **AI Agent 相关技术**：智能体架构与编排、上下文工程、工具调用 / MCP、检索与记忆、评测与可观测性，边看边实践边复盘
- **算法解题思路**：LeetCode 刷题的完整思考过程，不贴题解代码流水账，重点讲这道题是怎么想出来的、为什么这么做
- **随记与心得**：一些零碎的感悟、阶段性总结，以及对技术和工程化的个人思考
