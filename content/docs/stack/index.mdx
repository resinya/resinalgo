这里放具体技术点的文章，偏"弄明白一件事"：某个 API 到底怎么工作、
某个概念的边界在哪、某段代码为什么这么写。

## 大概会写什么

- **前端**：TypeScript、React / Next.js、CSS 与布局、浏览器行为
- **后端**：运行时、服务框架、数据层与缓存、接口设计
- **底层一点**：事件循环、内存与 GC、并发模型、网络协议
- **工具链**：包管理、构建工具、调试与 profiling

示例代码以 TypeScript 为主，能跑起来的尽量贴完整片段。
